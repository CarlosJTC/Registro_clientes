# 📋 Sistema de Registro de Clientes

Aplicación web sencilla para registrar clientes y el servicio contratado.

## 🚀 Funcionalidades
- Agregar clientes
- Mostrar lista de registros
- Validación de campos
- Interfaz simple y clara

## 🛠 Tecnologías utilizadas
- HTML
- CSS
- JavaScript

## 📌 Uso
1. Escribe el nombre del cliente
2. Escribe el servicio
3. Presiona el botón **Agregar**
4. El registro aparecerá en la lista
